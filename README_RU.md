# Minecraft Skin PNG → Chibi GLB v0.8.0

Небольшая автономная desktop-программа для Windows. Она читает стандартный
Minecraft-скин 64×64 и создаёт редактируемую chibi-модель в формате GLB.
Исходная PNG-текстура встраивается внутрь GLB, поэтому переносить её отдельным
файлом не нужно.

Версия 0.8.0 содержит единый настоящий glTF-риг и набор из 15 опциональных
клипов для tower defense. Проект по-прежнему работает без Blender
API, Unity, 3D-превью, скруглений и объёмных волос.
Доступна переносимая Windows x64 сборка с EXE, не требующая установленного Python.

## Что создаётся

В GLB находятся 12 отдельных объектов:

- `Head`, `Head_Overlay`;
- `Body`, `Body_Overlay`;
- `Arm.L`, `Arm.R`, `Arm_Overlay.L`, `Arm_Overlay.R`;
- `Leg.L`, `Leg.R`, `Leg_Overlay.L`, `Leg_Overlay.R`.

Overlay — настоящие отдельные меши, равномерно увеличенные относительно общего
центра базовых деталей. Базовый слой использует односторонний OPAQUE-материал,
а второй слой — отдельный односторонний MASK-материал с порогом 0.5. Оба
материала используют nearest-фильтрацию и clamp, чтобы сохранить пиксельный
рисунок без проблем сортировки прозрачности.

В поле **Материал** режим `Pixel Unlit` включён по умолчанию и добавляет
стандартное расширение glTF `KHR_materials_unlit`, чтобы Unity/glTFast не
создавал плавные световые градиенты. `PBR Lit` сохраняет прежнее освещаемое
PBR-поведение. В обоих режимах текстура, nearest sampler и alpha-настройки
остаются одинаковыми.

Все 12 мешей жёстко привязаны к одному скелету через стандартные glTF
`skins`, `inverseBindMatrices`, `JOINTS_0` и `WEIGHTS_0`. Скелет всегда имеет
12 костей: `Root`, `Hips`, `Spine`, `Head`, парные `Arm`/`Hand` и `Leg`/`Foot`.
Вспомогательные Hand и Foot пока не имеют собственной геометрии.

Все клипы работают in-place. `Root` всегда неподвижен, а scale и morph-weight
channels отсутствуют. Translation разрешён только для `Hips` в клипах
`SitIdle`, `WeaponIdle`, `Aim`, `AttackHeavySide` и `Death`; остальные клипы
остаются rotation-only. Посадка и финал падения вычисляются из текущих
пропорций, bind pose и геометрии, поэтому контакт с землёй сохраняется на
пресетах `Compact Chibi`, `Balanced Chibi` и `Big Head`.

`SitIdle` теперь использует единое направление модели: персонаж сидит на земле,
вытягивает ноги вперёд, отклоняет корпус назад и опирается руками позади себя.
`WeaponIdle` — спокойная low-ready стойка с условной винтовкой; `Aim` поднимает
ту же линию оружия в устойчивую прицельную позу. Геометрия оружия в GLB не
добавляется.

Зацикленные клипы:

- `Idle` — 2.4 с;
- `Walk` — 1.0 с;
- `Run` — 0.6 с;
- `Fall` — 1.0 с;
- `SitIdle` — 2.0 с;
- `ZombieWalk` — 1.2 с;
- `WeaponIdle` — 2.0 с;
- `Aim` — 1.5 с.

Одноразовые клипы:

- `Jump` — 0.45 с;
- `Land` — 0.35 с;
- `HitReact` — 0.35 с;
- `AttackOneHand` — 0.5 с, попадание примерно на 62% цикла;
- `AttackDualDaggers` — 0.9 с, попадания примерно на 30% и 68%;
- `AttackHeavySide` — 0.85 с, тяжёлый диагональный удар примерно на 60%;
- `Death` — 1.3 с, падение с удержанием финальной позы на земле.

Секция **Анимации** прокручивается и позволяет включить любой клип отдельно.
Кнопки **Весь набор · 15 клипов** и **Снять выбор**
управляют всем набором; выбор каждого checkbox сохраняется между запусками.
Реальное перемещение персонажа, высота прыжка, переключение состояний и момент
нанесения урона должны управляться кодом Unity.

## Требования

- Windows;
- Python 3.11.9 (проверяется при установке и запуске);
- интернет нужен только один раз для установки Python-пакетов, если они ещё не
  находятся в локальном кэше `pip`. Сама программа работает полностью офлайн.

## Готовая Windows-программа

Скачайте ZIP из Releases репозитория, распакуйте его целиком и запустите
`ChibiSkinGenerator.exe`. Папка `_internal` должна оставаться рядом с EXE.
Python и Blender для генерации не нужны. Приложение работает без интернета.

## Установка и запуск

1. Запустите `setup.bat`. Скрипт создаст `.venv` и установит зависимости.
2. После успешной установки запустите `run.bat`.
3. Выберите PNG 64×64.
4. Выберите `Steve`, `Alex` или `Auto`.
5. При необходимости откройте вкладку **Пропорции**, выберите пресет или
   измените параметры слайдерами и числовыми полями.
6. Выберите папку сохранения и нажмите **Создать GLB** на вкладке **Генератор**.

Результат сохраняется в выбранной папке под именем
`<имя_исходного_файла>_chibi.glb`.

## Steve, Alex и Auto

- Steve использует руки шириной 4 пикселя.
- Alex использует руки шириной 3 пикселя.
- PNG не содержит официального поля с типом модели. Поэтому `Auto` проверяет
  прозрачность неиспользуемых колонок slim-развёртки. Неоднозначный скин
  считается Steve. Если результат определён неверно, выберите тип вручную.

## Редактор пропорций

Вкладка **Пропорции** содержит связанные slider и `QDoubleSpinBox` для общего
масштаба, головы, корпуса, рук, ног и overlay. Изменения сразу отображаются на
схематичных видах спереди и сбоку и применяются к следующей генерации без
перезапуска программы.

Доступны встроенные пресеты `Compact Chibi` (по умолчанию), `Balanced Chibi`,
`Big Head` и `Legacy`. Встроенные пресеты нельзя удалить или перезаписать.
Пользовательские пресеты сохраняются в JSON в папке:

```text
%APPDATA%\ChibiSkinGenerator\presets
```

Кнопки **Сохранить пресет**, **Загрузить**, **Удалить пресет** и **Сбросить**
расположены в верхней части вкладки. Последние значения и выбранный пресет
сохраняются между запусками через системные настройки Qt.

## Импорт в Blender

В Blender выберите **File → Import → glTF 2.0**, затем созданный `.glb`.
Все части появятся отдельными объектами и останутся редактируемыми. В сцене
будет один Armature с 12 костями. Для проверки выберите Armature, перейдите в
**Pose Mode** и поверните, например, `Arm.L`: базовая рука и её overlay должны
двигаться вместе. Для позинга используйте `Head`, `Spine`, `Arm.L`, `Arm.R`,
`Leg.L` и `Leg.R`. Кости `Hand.L/R` и `Foot.L/R` пока являются только
вспомогательными точками без собственной геометрии. Данные alpha остаются в
MASK-материале и встроенной PNG.

Для просмотра клипа откройте рабочее пространство **Animation**, выберите
`Skeleton`, затем выберите нужный клип в **Dope Sheet → Action Editor**.
Запустите playback клавишей `Space`.

  rig.py            — стабильный скелет, pivots и диагностическая поза

  proportions.py    — настройки, диапазоны, пресеты и размещение частей

  preset_storage.py — безопасное JSON-хранилище пользовательских пресетов

tests/

  test_geometry.py
  test_uv_tables.py

## Тесты

Тестовый PNG создаётся программно во временной папке; сторонних ассетов в
репозитории нет.

```bat
.venv\Scripts\python.exe -m pytest
```

## Проверка выразительности AttackHeavySide

Клип сохраняет длительность 0.85 с и hitTime 0.51 с. Выраженный замах
задерживается перед быстрым диагональным ударом; корпус опережает руки,
обе руки идут в одном направлении сверху вниз; после доведения следует
спокойный возврат в готовую стойку без пружинного отскока.
Восстановлена версия с плавным переносом веса и постоянной шириной стойки.
Последние изменения с прямым ударом и неподвижными ногами отменены.
Высота Hips вычисляется по нижней точке геометрии. Плотные ключи сохраняют
контакт с полом между основными позами без root motion или новых костей.

`python tools/preview_heavy_attack.py` создаёт отдельный проверочный GLB,
программный скин, GIF до/после и замедленную версию в
`verification_output/heavy_attack_review/`. Для старого клипа используется версия
`animations.py` из текущего Git HEAD. Просмотр содержит диагностическое
освещение; в приложении 3D-превью не добавляется.

## Исправления по результатам проверки

- Формат PNG проверяется по содержимому; размеры проверяются до декодирования пикселей.
- Повторная генерация сохраняет `_2.glb`, `_3.glb` и далее. Существующие файлы
  не заменяются, в том числе при одновременной генерации в нескольких окнах.
- Ошибки доступа к пресетам показываются понятным сообщением. Зарезервированные
  Windows имена (CON, NUL, COM1 и т. п.) запрещены.
- Для пяти клипов с разрешённым движением Hips контакт базовой геометрии с
  землёй рассчитывается на плотной сетке 120 Гц, включая промежуточные позы Death.
  Проверочная интерполяция вращений использует SLERP, как glTF LINEAR.
- Миниатюра показывает исходный атлас PNG без сглаживания. PNG можно перетащить
  в окно. Пути и тип рук сохраняются; папка результата открывается кнопкой.
- Список клипов разделён на циклические и однократные, указана длительность.
- `requirements.txt` фиксирует полный набор версий проверенного окружения.
  `setup.bat` не обновляет pip автоматически и проверяет версию существующей .venv.

Неподвижный Root, запрет scale и список разрешённых Hips translation сохранены.
Walk/Run остаются rotation-only по требованиям проекта; физический контакт ног
в них ограничен жёсткими кубическими конечностями без коленей. Новые кости,
root motion и 3D-превью в приложение не добавлены.

## Сборка Windows EXE

На Windows с Python 3.11.9 выполните `setup.bat`, затем `build.bat`.
В `dist/` появятся папка программы, ZIP и контрольная сумма SHA-256.
Перед созданием ZIP сборка проверяет запуск интерфейса и экспорт всех 15 клипов
из самого EXE с очищенными PYTHONPATH/PYTHONHOME и минимальным PATH.
Проверка на текущей машине не заменяет испытания на всех версиях Windows.
